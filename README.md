# Windows 2020

This project was started in 2020 during the COVID lockdown in New York City. At that time, all I could really do was look out the window. I had intended to make a website that reflected on this practice — a series of stories about running into people on the street, paired with a window to look through.

Unfortunately the project never got off the ground, but I still feel like it's interesting. I might return to it at some point. 

For now it's an idea in the bank.
